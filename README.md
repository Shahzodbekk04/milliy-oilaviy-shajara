# Milliy Oilaviy Shajara — ikonkalari tuzatilgan versiya

Muhim:
- Ikonkalar endi JavaScript orqali chizilmaydi.
- Ular `assets/icons/` ichidagi haqiqiy `.svg` rasm fayllari sifatida berilgan.
- ZIP faylni TO‘LIQ chiqarib oling, so‘ng `index.html` ni oching.
- `index.html` ni papkadan ajratib alohida ko‘chirsangiz, rasm/ikonka yo‘llari buzilishi mumkin.

Papka tuzilishi:
- index.html
- reference.png
- assets/icons/*.svg
